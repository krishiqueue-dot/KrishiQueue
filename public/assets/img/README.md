Optional poster frame for the problem film.

The player sets no poster by default, so the browser holds the film's own
first frame — which is usually the right image. If you want a different
still, export it here and point `POSTER_SRC` in
`src/components/sections/ProblemFilm.tsx` at it.

Recommended: 1280x720 to match the film, JPEG, under 250 KB.
